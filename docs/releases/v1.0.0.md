# Factory OS v1.0.0

Release date: 2026-02-23

## Highlights

- Unified command surface via `bash factory.sh`:
  - `start`, `stop`, `restart`, `status`, `repair`, `selftest`, `version`
- Crash-safe startup and stop behavior with idempotent service handling.
- Deadlock-safe queue recovery with lease rescue integration.
- Self-healing repair command for worker/daemon recovery.
- Public OSS baseline:
  - `LICENSE`, `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`
  - CI workflow and issue/PR templates

## Operational Baseline

- Queue lifecycle: `incoming -> leased -> done|failed`
- Runtime telemetry:
  - `runtime/metrics.jsonl`
  - `runtime/task_state.json`
  - `runtime/codex_sessions.json`
- Selftest command validates queue flow, metrics write, lease rescue, session reuse, and optional API health.

## Notes

- API server is optional; system remains operational when unavailable.
- Build quality is measurable and repairable, but perfect generation is not guaranteed.
