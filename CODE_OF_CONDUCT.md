# Code of Conduct

## Our Standard

We are committed to a respectful, inclusive, and technically rigorous community.

Expected behavior:

- Be respectful and constructive in technical discussions.
- Focus on evidence, reproducibility, and clear reasoning.
- Accept feedback and collaborate in good faith.

Unacceptable behavior:

- Harassment, discrimination, or abusive language.
- Personal attacks or intimidation.
- Publishing private information without consent.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, and pull requests
that violate this Code of Conduct.

For reports, open a private security-style report as described in `SECURITY.md`.
